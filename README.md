# 잎의 작은 차이 — 과학 탐구 웹 프레젠테이션

**잎 표면 구조에 따른 미세먼지 흡착률 비교** · 광주중학교 유민수, 정은우

첨부 PDF와 HWP 보고서로 구성한 15장, 16:9 발표자료입니다. HTML·CSS·Vanilla JavaScript만 사용하며 서버 API·데이터베이스·빌드 과정은 필요하지 않습니다. PowerPoint 파일이 아닌 웹 발표자료입니다.

## 실행

**가장 간단한 실행:** 소스 ZIP을 압축 해제하고 `offline.html`을 Chrome 또는 Edge에서 열면 됩니다. 사진·폰트·코드가 모두 들어 있어 인터넷이나 서버가 필요하지 않습니다.

일반 웹사이트 버전은 이 폴더에서 다음 명령을 실행한 뒤 `http://localhost:8000`을 엽니다.

```sh
python -m http.server 8000
```

분리된 소스인 `index.html`을 더블클릭하는 `file://` 실행은 권장하지 않습니다. 더블클릭 실행에는 `offline.html`을 사용하세요. 브라우저 정책에 따라 IndexedDB나 원본 이미지의 JSON 내보내기가 제한될 수 있습니다. 웹 서버는 정적 파일을 제공할 뿐, 사용자 데이터는 서버에 저장하지 않습니다.

## 발표

- **발표 시작**: 앱 도구를 숨기고 전체 화면을 요청합니다.
- **← / →**: 이전 / 다음 슬라이드. Home / End는 처음 / 마지막.
- **F**: 전체 화면 전환. **H**: 컨트롤 표시 / 숨기기.
- 컨트롤이 숨겨져도 방향키로 이동할 수 있고, 마우스를 움직이면 다시 표시됩니다.
- **Esc**: 발표 종료. 편집 미리보기에서는 편집 화면으로 돌아갑니다.
- 자료 메모에서 원문 출처, 해석상의 한계, 자료 간 차이를 확인할 수 있습니다.

## 편집

상단 **편집 모드**를 누릅니다. 기본 배치를 보호하기 위해 위치 이동은 잠겨 있습니다.

- 글자: 클릭해 입력, Enter 줄바꿈. 오른쪽에서 크기·색상·굵기·정렬 조정. **T 글자**로 문장 추가, **이 요소 삭제**로 삭제.
- 사진: 클릭해 선택, **사진 교체하기** 또는 두 번 클릭. 사진 추가·삭제, 표시 방식(전체/채우기), 표시 영역과 모서리 조정. 이미지 파일을 슬라이드에 드래그해서 추가할 수도 있습니다.
- 위치: **위치와 크기 세부 조정**에서 좌표·너비·높이 입력. **드래그로 배치 허용**을 켜면 사진·도식·그래프를 이동할 수 있습니다. 글자는 선택 영역 위의 작은 손잡이를 드래그합니다.
- 슬라이드: 추가·복제·삭제·배경 변경. 위/아래 이동 버튼 또는 왼쪽 목록 드래그로 순서 변경.
- 그래프: 클릭 후 식물 이름·수치·색상 수정. 수치가 즉시 반영됩니다. 제목은 슬라이드의 제목을 클릭해 수정합니다. 앞면 부착률의 최고 수치와 식물 이름은 그래프와 자동 연결됩니다.
- **Ctrl/⌘ Z**, **Ctrl/⌘ Y** 또는 ↶/↷: 실행 취소·다시 실행. 변경 이력은 현재 탭에서 최대 35개 유지합니다.
- **미리보기**: 도구가 없는 발표 화면 확인. **이번 편집 취소**: 편집 모드 진입 전으로 복원.

## 저장 및 백업

- 변경 후 약 0.8초에 **IndexedDB**에 자동 저장합니다. **저장**, **Ctrl/⌘ S**로 즉시 저장할 수도 있습니다.
- 사진 파일도 브라우저에 저장하며 최대 1800px로 축소합니다. 입력 이미지는 20MB 이하 PNG/JPG/WebP/GIF(첫 프레임)입니다.
- 브라우저·PC·웹사이트 주소마다 저장소가 분리됩니다. 시크릿 모드나 사이트 데이터 삭제 후에는 유지되지 않을 수 있습니다.
- **파일 → 발표자료 내보내기**: 텍스트, 구성, 그래프, 모든 이미지를 포함하는 JSON을 내려받습니다.
- **파일 → 발표자료 불러오기**: 다른 브라우저에서도 JSON 파일로 복원합니다. 현재 자료를 교체하기 전에 확인을 표시합니다.
- **원본 자료 백업**: 수정 전 15장을 이미지 포함 JSON으로 내보냅니다. **전체를 원본으로 되돌리기**: 현재 자료 초기화.
- 저장 공간 부족·권한 오류·잘못된 JSON은 화면에 안내합니다. 저장이 실패하면 JSON으로 백업하세요.
- 최대 60장, JSON 가져오기 80MB 제한. 편집 내용은 서버로 업로드되지 않습니다.

## 파일 구조

```text
offline.html     더블클릭 실행용 단일 HTML (모든 사진·폰트 포함)
index.html       앱 구조와 편집/발표 UI
style.css        16:9 디자인, 슬라이드별 레이아웃, 전환 효과
app.js           발표, 편집, IndexedDB, JSON, 실행 취소/재실행
slides.js        15장 원본 내용과 측정값
assets/          원자료 이미지, 한국어 폰트, 폰트 라이선스
SOURCES.md       원자료와 해석 기준
TESTING.md       수행한 검증 및 범위
.nojekyll        GitHub Pages 정적 파일 제공용
tools/           단일 HTML 재생성 스크립트
```

## GitHub Pages

저장소의 Settings → Pages에서 이 파일이 있는 브랜치의 `/ (root)`를 선택하면 됩니다. 모든 앱·이미지·폰트 경로는 상대 경로이므로 저장소 하위 주소에서도 동작합니다. 외부 CDN이나 패키지 설치가 필요하지 않습니다. Pages 설정은 별도로 변경하지 않았습니다.

기본 수정 내용은 로컬에만 저장됩니다. 모든 방문자에게 기본 슬라이드 변경을 배포하려면 내보낸 JSON의 데이터로 `slides.js`의 `window.DEFAULT_DECK`을 갱신하고 저장소에 반영합니다.

`offline.html`은 `python tools/build-standalone.py`로 재생성합니다. 기본 파일 주소에서 저장소를 사용할 수 없는 브라우저에서는 JSON 백업을 사용하거나 정적 웹 서버로 실행하세요.
