# 잎 표면 구조에 따른 미세먼지 흡착률 비교

정은우 · 유민수의 인터랙티브 과학 연구 발표입니다. `3D Botanical Lab`은 내부 프로젝트·디자인 콘셉트 이름입니다. 공식 연구 제목은 위 제목을 그대로 사용합니다.

기존 식물 그래픽과 CSS 애니메이션을 유지하면서 20개 섹션을 구현했습니다. 외부 폰트, CDN, 3D 라이브러리, 런타임 패키지가 필요하지 않습니다. 입체 모형은 HTML/CSS 설명용 그래픽이며 실제 실험 사진이 아닙니다.

## 실행 방법

저장소 루트에서 실행합니다. Python 3이 있으면 별도의 패키지 설치가 필요 없습니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 열어 확인합니다.

## 정적 빌드와 검사

Node.js 18.17 이상에서 추가 패키지 설치 없이 실행할 수 있습니다.

```bash
npm run check
npm run build
python3 -m http.server 8000 --directory dist
```

빌드는 공식 제목, 섹션 수, 내부 링크와 정적 자산 경로를 확인한 뒤 `dist/`에 배포 파일을 복사합니다. 서버에서 컴파일할 코드는 없으며, 생성된 `dist/`를 정적 호스팅에 사용할 수 있습니다. 원본 파일을 삭제한 뒤 다시 배포할 경우 `dist/`의 이전 파일이 남지 않도록 새 출력 폴더에서 빌드하세요.

브라우저 회귀 테스트는 Playwright와 Chromium이 있는 환경에서 실행합니다. 현재 클라우드 환경에는 두 도구가 설치되어 있습니다. 다른 환경에서는 다음처럼 테스트 도구를 준비할 수 있습니다(사이트 실행·빌드에는 필요 없음).

```bash
npm install --no-save --package-lock=false playwright@1.62.1
npx playwright install chromium
npm run build
npm test
```

시스템 Chromium은 `/usr/bin/chromium`에서 자동 감지하며, 다른 경로는 `CHROMIUM_PATH=/path/to/chromium npm test`로 지정합니다. 그 외에는 Playwright가 설치한 브라우저를 사용합니다. 테스트는 임시 로컬 서버를 직접 시작하고 종료합니다. 결과 스크린샷은 Git에서 제외된 `test-results/`에 저장됩니다.

검증 대상: 제목·연구자, 20개 섹션, 원자료·흡착률, 목차·이전/다음·키보드 이동, 전체 화면, 5개 화면 크기, 사진 교체·오류 복구, JavaScript 비활성화, 애니메이션·동작 줄이기, 콘솔 오류. 잘못된 사진 경로와 표지 이미지 실패는 별도 테스트 페이지에서 의도적으로 재현합니다.

## 프로젝트 구조

```text
.
├── index.html
├── assets/
│   ├── images/             # 기존 표지 그래픽과 파비콘
│   └── photos/             # 실제 실험 사진 (아직 없음)
├── scripts/
│   ├── main.js             # 탐색·발표 제어·애니메이션·사진 복구
│   └── build.mjs           # 의존성 없는 정적 빌드
├── styles/
│   ├── main.css            # 기존 표지 디자인
│   └── presentation.css    # 발표 섹션과 반응형 확장
├── tests/presentation.cjs  # 실제 Chromium 회귀 테스트
└── package.json
```

## 발표 구성과 조작

표지 → 목차 → 연구 동기 → 목적과 가설 → 표면 구조 → 털 → 왁스층 → 평평한 표면 → 테이프 전사법 → Python·OpenCV → 식물 4종 → 실험 장치 → 활성탄 분산 → 자연 침강 → 테이프 전사 → 이미지 분석 → 측정 결과 → 앞면 흡착률 → 결론과 한계 → 후속 연구.

- 목차와 하단의 이전/다음 버튼으로 이동합니다. 현재 섹션 번호·이름·진행 막대가 표시됩니다.
- 방향키 `←`/`↑`는 이전, `→`/`↓`는 다음 섹션으로 이동합니다. 입력란, 편집 영역, 링크, 버튼, 상세 안내 등에서는 방향키를 가로채지 않습니다.
- 전체 화면 버튼으로 시작·종료합니다. 지원하지 않는 브라우저에는 안내를 표시합니다.
- 모바일에서는 표지의 반복 움직임과 포인터 효과를 줄입니다. OS의 동작 줄이기 설정을 존중합니다.
- JavaScript가 비활성화되어도 본문·표·그래프·목차의 기본 링크를 읽고 사용할 수 있습니다.

## 실제 사진 넣기

각 사진 자리에는 사진 종류, 권장 비율, 폴더와 교체 방법이 표시됩니다. 총 9곳입니다. 사진이 없으면 빈 경로를 유지하세요. 존재하지 않는 파일을 미리 요청하지 않습니다.

1. 실제 촬영 이미지를 `assets/photos/`에 넣습니다. [파일명·비율 목록](assets/photos/README.md)을 참고하세요.
2. `index.html`에서 해당 사진의 `alt`를 찾아 같은 `<img>`의 빈 `data-photo-src`에 경로를 입력합니다.

```html
<img data-photo-src="assets/photos/rubber-plant.jpg"
     alt="고무나무 실제 식물 사진" width="1200" height="900" hidden />
```

3. 사진에 맞게 `alt`를 수정합니다. JPG, PNG, WebP 사용 가능하며 파일명과 확장자는 경로와 정확히 맞아야 합니다.
4. 서버에서 확인하고 배포용 파일은 `npm run build`로 갱신합니다.

권장 비율은 식물 4종·챔버·분산·침강·전사 사진은 4:3, 분석 화면은 16:10입니다. 사진은 잘리지 않도록 표시됩니다. 잘못된 경로를 넣으면 안내 화면으로 복구하며, 브라우저 네트워크 로그에는 해당 요청 실패가 남을 수 있습니다. 사진을 추가한 경우 JavaScript가 없는 환경에서는 안내 슬롯이 유지됩니다.

## 데이터와 해석의 범위

측정 면적(cm²) 원자료와 보고서의 앞면 흡착률(%)은 별도 지표로 표시합니다. 측정 영역 크기, 흡착률 계산식, 이미지 보정값·임계값, 반복 실험 자료는 제공되지 않았으므로 계산식을 만들거나 면적당 값으로 변환하지 않았습니다. Python·OpenCV 섹션은 분석 원리를 설명하며 실제 분석 프로그램을 실행하지 않습니다. 활성탄 실험만으로 실제 공기 정화 성능을 단정하지 않습니다.
